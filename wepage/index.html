How we're brewed

One counter, two baristas working in sync

An AWS Network Load Balancer sits at the front counter, greeting every customer and sending them to whichever barista is free. Neither line ever gets too long, and if one barista steps out, the other keeps the café running without a single missed order.

The front counter

Every request lands on the Network Load Balancer first. It doesn't make coffee itself — it just knows exactly who's free to help next.

Two identical stations

Both instances run the same image, so your order tastes the same no matter which one takes it.

Constant health checks

The counter quietly checks in on both baristas every few seconds. A station that goes quiet is taken off the list until it's back.
